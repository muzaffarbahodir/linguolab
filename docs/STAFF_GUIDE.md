# LinguoLab — шпаргалка для персонала (1 страница)

Всё делается в приложении: откройте бота в Telegram → приложение откроется само.
Раздел **Админка** виден менеджерам и администраторам.

---

## 🧑‍🏫 Учителю

| Что | Где | Как |
|---|---|---|
| Открыть курс | Мои курсы → «Заявка на курс» | Заполните язык/уровень/дни/время → менеджер апрувит → группа создаётся сама |
| Расписание/дата старта/Zoom | Карточка класса → «Настройка» | Уроки на 4 недели создаются автоматически при старте группы |
| Отметить посещаемость | Класс → урок → галочки → Сохранить | Сразу после занятия. Урок закроется сам через 6ч, но **без посещаемости** — придёт напоминание через 2ч |
| Отменить / перенести урок | Класс → урок → «Отменить» / «Перенести» | Студенты получат уведомление сами. Отменённый урок не идёт в зарплату |
| Домашнее задание | Класс → вкладка ДЗ → «+» | Студенты и родители уведомляются сами; проверяйте сдачи там же |
| Сертификаты | — | Выдаются автоматически при завершении курса. Вручную: карточка студента → «Выдать сертификат» |

## 🧑‍💼 Менеджеру

| Что | Где | Как |
|---|---|---|
| Апрув курса | Админка → Заявки на курсы | Проверьте цену/даты/кабинет → «Одобрить». Даты можно не заполнять — подставятся сами (запись сразу, семестр = 1 месяц). Конфликт времени у учителя/кабинета — система не даст сохранить |
| Заявки на запись | Админка → Записи | PENDING → «Подтвердить» после оплаты. Неоплаченные заявки чистятся сами через 3 дня |
| Принять наличные | Студент показывает QR-чек → Админка → «Скан» | Отсканируйте (или введите номер) → «Подтвердить оплату». Доступ и чек — автоматически |
| Возврат | Админка → Финансы → платёж → «Возврат» | Блокируется, если студент прошёл >3 занятий. Деньги вернуть в кабинете Click **вручную** — система напомнит в ответе |
| Привязать TG-чат класса | Добавьте бота в группу класса | Бот напишет туда ID → Админка → Классы → «Привязать TG-чат» → вставьте ID. Без чата студенты не получат инвайт! |
| Кабинеты | Админка → Кабинеты | Создайте кабинеты один раз; назначаются при апруве курса. Двойное бронирование блокируется |
| Перевод студента | Админка → Переводы | Одобрить/отклонить; место в старой группе уйдёт очереди само |

## 🤖 Что делает система сама (не трогать)

- Открытие/закрытие набора, старт и завершение семестра — по датам.
- Генерация уроков, выдача сертификатов, продвижение листа ожидания.
- Напоминания: об оплате (за 3 дня и при просрочке), об уроке (за 1ч), о ДЗ, «вернись» спящим.
- Снятие доступа у неплательщиков (через 7 дней просрочки) и чистка неоплаченных броней (3 дня).
- Кэшбэк-баллы, реферальные бонусы, фискальные чеки.

## 🆘 Если что-то не работает

1. Студент «не видит группу» → проверьте оплату (Финансы) и статус записи (Записи).
2. «Не приходят уведомления» → студент мог заблокировать бота; попросите нажать /start.
3. Всё лежит → напишите владельцу; мониторинг сам пришлёт алерт в Telegram.
